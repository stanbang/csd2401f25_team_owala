# balabingbong

Game project created with the Owala Engine editor.

## Folder Structure

| Folder | Purpose |
|--------|---------|
| `Assets/Audio/` | Raw audio files (SFX / Music) |
| `Assets/Fonts/` | Font files (.ttf / .otf) |
| `Assets/Sprites/` | Raw sprite / texture images |
| `Data/AnimationData/` | Animation definition JSON files |
| `Data/Config/` | Project and engine config files |
| `Data/FSM/` | Finite-state machine definition files |
| `Data/ParticleEffects/` | Particle effect preset files |
| `Data/Prefabs/` | Entity prefab JSON files |
| `Data/SaveData/` | Runtime save / progress data |
| `Data/Scenes/` | Serialised scene JSON files |
| `Data/Shaders/` | GLSL shader source files |
| `Source/` | C++ game code and the `CreateApplication` entry point |
