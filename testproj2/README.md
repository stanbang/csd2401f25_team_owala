# testproj2

Game project created with the Owala Engine editor.

## Folder Structure

| Path | Purpose |
|------|---------|
| `Assets/Audio/` | Raw audio files (SFX / Music) |
| `Assets/Fonts/` | Font files (.ttf / .otf) |
| `Assets/Sprites/` | Raw sprite / texture images |
| `Data/AnimationData/` | Animation definition JSON files |
| `Data/Config/` | Additional engine config files |
| `Data/FSM/` | Finite-state machine definition files |
| `Data/ParticleEffects/` | Particle effect preset files |
| `Data/Prefabs/` | Entity prefab JSON files |
| `Data/Scenes/` | Serialised scene JSON files |
| `Data/audioFiles.json` | Registry of all audio assets |
| `Data/config.json` | Project and engine configuration |
| `Data/LayerConfig.json` | Collision and render layer setup |
| `Data/scenes.json` | Registry of all scene assets |
| `Data/stateToAnimationMapping.json` | FSM state to animation mapping |
| `Data/textureToAnimationMapping.json` | Texture to animation data mapping |
| `Source/` | C++ game code and `CreateApplication` entry point |
